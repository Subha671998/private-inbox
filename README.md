# Private Inbox

Private Inbox is a modern messaging platform built with React and Firebase.

## Features

- Phone OTP Login
- Email Login
- Friend Requests
- Private Chat
- Group Chat
- Image & Video Sharing
- Admin Dashboard
- Firebase Authentication
- Firebase Firestore
- Firebase Storage

## Technology

- React
- Firebase
- JavaScript
- HTML
- CSS
